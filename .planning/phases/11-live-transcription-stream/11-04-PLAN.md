| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-07 | Denial of Service | processStream onToken loop | mitigate | TranscriptionQueue remains serial (D-06) — only one processStream call active at a time. No concurrent CoreML contention possible. |
| T-11-08 | Tampering | tempURL path | mitigate | MeetingRecorder always uses FileManager.default.temporaryDirectory.appendingPathComponent(...) — app-controlled path, not user-supplied. WAV file is deleted immediately via defer block after transcription. |
| T-11-09 | Information Disclosure | partialText in onToken | accept | Partial text is identical in sensitivity to the final transcription. Already handled by the existing sensitive-data log guard (GenericHelper.logSensitiveData()). |
| T-11-10 | Elevation of Privilege | VoiceToTextFactory.createVoiceToText() | accept | Factory reads user settings (sttEngine) which is app-controlled. No external input influences which engine is selected. |
