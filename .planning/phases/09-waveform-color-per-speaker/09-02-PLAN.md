New implementation:

1. **Named constants** — define at the top of the struct:
   ```swift
   /// Noise floor in dB. Levels at or below this render at minimum bar height.
   private let noiseFloor: Float = -50
   /// Minimum bar height in points. Bars at or below the noise floor render at this height.
   private let minBarHeight: CGFloat = 4
   ```

2. **State properties** — replace `@State private var levels: [Float]` with parallel arrays:
   ```swift
   @State private var levels: [Float] = Array(repeating: 0, count: 50)
   @State private var speakerLabels: [String] = Array(repeating: "", count: 50)
   ```
   Keep `private let maxSamples = 50` and the existing timer (`Timer.publish(every: 0.1, ...)`).

3. **Body** — replace the `GeometryReader > HStack > ForEach` with a `Canvas`:
   ```swift
   var body: some View {
       Canvas { context, size in
           let spacing: CGFloat = 3
           let barWidth = (size.width - CGFloat(maxSamples - 1) * spacing) / CGFloat(maxSamples)

           for index in 0..<levels.count {
               let level = levels[index]
               let label = speakerLabels[index]
               let speaker = Speaker(displayName: label)
               let color = speakerPaletteColor(speaker)

               // Scale bar height relative to noise floor:
               // - level is in dB (negative). noiseFloor = -50.
               // - Anything at or below noiseFloor renders at minBarHeight.
               // - 0 dB (max) renders at full size.height.
               // - Formula: normalized = (level - noiseFloor) / (0 - noiseFloor)
               //   clamped to [0, 1], then scaled to [minBarHeight, size.height]
               let normalized = max(0, min(1, (level - noiseFloor) / (0 - noiseFloor)))
               let height = max(minBarHeight, normalized * size.height)
               let x = CGFloat(index) * (barWidth + spacing)
               let y = (size.height - height) / 2

               let rect = CGRect(x: x, y: y, width: barWidth, height: height)
               let path = RoundedRectangle(cornerRadius: 2).path(in: rect)
               context.fill(path, with: .color(color))
           }
       }
       .onReceive(timer) { _ in
           updateLevels()
       }
       .onChange(of: recorder.isRecording) { _, isRecording in
           if isRecording {
               // Clear history for new recording
               levels = Array(repeating: 0, count: maxSamples)
               speakerLabels = Array(repeating: "", count: maxSamples)
           }
       }
   }
   ```

   **IMPORTANT — noise floor scaling formula:**
   The `normalizedLevel` from MeetingRecorder is a 0-to-1 float, NOT dB. The noise floor scaling must convert to the correct range. Since `normalizedLevel` is already linear 0-1, the noise floor constant should be applied as follows:
   - Define `let noiseFloor: Float = -50` as a named constant
   - Convert normalizedLevel to dB-like scale: `let levelDB = 20 * log10(max(level, 1e-7))`
   - Normalize: `let normalized = max(0, min(1, (levelDB - noiseFloor) / (0 - noiseFloor)))`
   - Final height: `let height = max(minBarHeight, normalized * size.height)`

   This means bars at silence (level ~0, which maps to well below -50dB) render at `minBarHeight` (4pt), and bars at full volume (level ~1, which maps to 0dB) render at full height. The -50dB threshold controls where bars start growing beyond the minimum.

4. **Remove** `barWidth(geo:)`, `barHeight(for:in:)`, and `barGradient(for:)` private methods entirely — Canvas replaces all of them.

5. **updateLevels()** — rewrite to maintain both parallel arrays:
   ```swift
   private func updateLevels() {
       guard recorder.isRecording else {
           if levels.allSatisfy({ $0 < 0.001 }) || levels.count < maxSamples {
               levels = (0..<maxSamples).map { i in
                   Float(sin(Double(i) * 0.3)) * 0.1 + 0.1
               }
               speakerLabels = Array(repeating: "", count: maxSamples)
           }
           return
       }

       let newLevel = recorder.normalizedLevel
       let currentSpeaker = recorder.activeSpeakerLabel

       levels.append(newLevel)
       speakerLabels.append(currentSpeaker)

       if levels.count > maxSamples {
           levels.removeFirst()
           speakerLabels.removeFirst()
       }
   }
   ```

6. **No animation** on color change — Canvas draws immediately, no `withAnimation` anywhere in the new waveform code. The `.animation(.easeOut(duration: 0.1), value: levels[index])` from the old HStack implementation must be completely removed.

7. **Init signature** remains `MeetingWaveformView(recorder:)` — no changes to call-sites. Verify `MeetingNotesView.swift` still uses `MeetingWaveformView(recorder: recorder)`.
