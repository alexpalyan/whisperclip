- `func deleteLLMModel(modelName: String)` - calls `ModelStorage.shared.deleteModel(modelRepo: "\(CurrentLLMModelRepo)/\(modelName)", modelName: "")`, handles fallback selection via `ModelStorage.shared.getDownloadedLLMModelNames().first(where: { $0 != modelName }) ?? CurrentLLMModelName`, calls `refreshModelsSize()`.

- `func deleteAllModels()` - calls `ModelStorage.shared.deleteAllModels()`, logs, calls `refreshModelsSize()`.

- `func refreshModelsSize()` - sets `totalModelsSize = ModelStorage.shared.getTotalModelsSize()`.

Note: The `downloadLLMModel` method should NOT be `async` at the call site. It should create an internal `Task { ... }` just like the current View implementation does, so the View can call it as a simple sync function from a Button action.
